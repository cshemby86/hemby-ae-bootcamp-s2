# Functional Requirements for TODO App

## Core Task Management

1. The user can create a new task with a required title.
2. The user can edit an existing task title.
3. The user can delete a task.
4. The user can mark a task as complete or incomplete.
5. The user can view all tasks in a list.

## Task Details

1. The user can add an optional description to a task.
2. The user can add or remove a due date for a task.
3. The user can add one priority level to a task (for example: low, medium, high).

## Organization and Sorting

1. The user can sort tasks by due date.
2. The user can sort tasks by priority.
3. The user can sort tasks by creation date.
4. The user can choose ascending or descending sort order.

## Filtering and Search

1. The user can filter tasks by status (all, active, completed).
2. The user can filter tasks by due date state (overdue, due today, upcoming, no due date).
3. The user can search tasks by title or description text.

## Usability and Persistence

1. The app saves tasks so they are still available after refresh or restart.
2. The app validates required fields and shows a clear message when input is invalid.
3. The app confirms before permanently deleting a task.
